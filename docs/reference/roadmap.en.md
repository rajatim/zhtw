# Roadmap

This roadmap shows direction, not promised dates. Compatibility or scope changes will first be reviewed through issues, design documents, and tests.

## 4.5.0: complete

- JSON string-value adapter.
- Cross-SDK `explain` with stable rule events.
- Rule schema v2 and human review metadata.
- Stronger cross-SDK packaging, verification, and release evidence.
- Bilingual public product documentation and documentation gates.

## 4.6.0: next stage

- Study explicit `domain` profiles without letting metadata change existing output before there is a clear contract.
- Improve custom-rule authoring, validation errors, and migration tools.
- Improve CLI and SDK guides from real user questions instead of creating many empty pages.
- Prepare independent data and governance for the next fresh benchmark.

## 4.7.0 and 5.0.0: conditional direction

- Expand profiles, context, or structured adapters only after their public contracts are mature.
- Move to 5.0.0 only when an incompatible change is truly needed. A schedule alone does not justify a major version.

Blind-v3 has not run, and it is not a 4.5.0 release condition. A new accuracy claim must freeze its version, data, and scoring method before results are published.

Open a [GitHub Issue](https://github.com/rajatim/zhtw/issues) for proposals. See [Contributing](../guides/contributing.md) for conversion reports.
